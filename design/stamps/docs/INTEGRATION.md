# 수도권42 적용 안내

이 패키지는 기존 시제품10개를 덮어쓰지 않는 추가분입니다. stamps42개와 seasons168개를 같은 폴더에 병합합니다. 기존 모티프9개는 바이트 단위로 같으며 새4개만 추가하면 됩니다. season-tokens.json은 기존10개와 신규42개의 mountainPaletteTypes를 합친52개 매핑입니다. 다른 운영 매핑이 이미 있다면 객체를 통째로 교체하지 말고 신규42 ID만 병합하세요.

## ID와 컬렉션

모든 ID는 문자열입니다. 10자리 숫자의 선행0과 osm- 접두사를 보존합니다. 이름이 비슷해도 백운산(포천)·백운산(의왕), 불곡산(성남)·다른 불곡산을 합치지 않습니다. assignments의 collection은 hundred/local이며 컬렉션 구분은 ID에 의존해 추측하지 않습니다. 표기고도와 인증 지점명은 의뢰서 값을 그대로 보존했습니다.

## 그림과 상태

앱은 인증 한국시간의 계절판을 씁니다. 기본판은 편집 원본입니다. 봄/여름/가을은 자체 색과 gradient를 포함하고 겨울은 승인된 기존 슬롯 체계를 씁니다. 겨울 ridge: <600 #6E955C, <1000 #377650, <1500 #245744, 그 이상 #30485A. paper #FCFBF7, ink <1500 #234D36, 그 이상 #203442, accent #B9D1D1. ridge-back은 같은 산색에 opacity .6.

기존 링 r85/r77, 원 중심90,90, 그림 clip r73, 주황 해r20는 호스트가 그립니다. 해 위치는 assignments.sun, 하늘은 season-tokens의 계절값. 호스트 자동 눈과 장식 전경은 끄고 그림 층 자체 눈·전경을 사용합니다. 이번42곳은 봄 잔설 대상이 없으며 겨울에는 자체 눈이 있습니다.

공유 모티프는 같은 SVG defs로 합쳐 로컬 href를 씁니다. 모티프 none인 산에는 use가 없습니다. filter/gradient/clipPath/symbol ID와 모든 url/href 참조를 인스턴스별로 고유하게 만드세요. 소백산 계절용 보조symbol 등 기존 파일 내부 ID는 보존합니다.

40px: lg-only와 collected-only를 숨기고 filter 제거. 능선 그라데이션은 유지. 미모음: 내부 장식·눈·계절층·필터·해를 숨기고 모든 paint/gradient를 #D4DACE로 치환, 후경opacity1. CSS ridge 변수 하나만 바꾸면 봄/여름/가을의 자체색이 남으므로 기존 단색 렌더를 사용하거나 모든 fill/stroke를 치환합니다.

standalone의 SVG는 모티프와 색을 해석한 독립 파일이고 PNG는600×600 원 밖 투명입니다. preview는40/76/160px 모음·미모음 실제 크기입니다. assets의 sourceSVG는 외부 모티프와 호스트 색·클립이 필요합니다.
