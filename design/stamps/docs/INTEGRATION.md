# 2차 적용 안내

기본판은 편집 원본이며 앱에는 인증 시각에서 선택한 계절판을 사용합니다. 3–5월 봄, 6–8월 여름, 9–11월 가을, 12–2월 겨울: 기존 한국 시간 기준을 유지합니다.

- 봄·여름·가을 SVG는 자체 색과 그라데이션을 포함합니다. 기존 고도색으로 덮어쓰지 않습니다. 모티프의 인라인 CSS 변수는 같은 심볼을 서로 다른 계절색으로 칠하기 위한 것입니다.
- 겨울 SVG는 합격본과 바이트 단위로 같습니다. 기존 고도별 ridge, ridge-back, paper, ink, winter accent 슬롯을 공급합니다. 값은 season-tokens.json의 winterPalette에 기록했습니다.
- 모티프 파일은 변경하지 않았습니다. 외부 symbol을 같은 SVG defs로 합친 뒤 로컬 href로 바꿔야 합니다. 필터·gradient·clipPath·symbol의 ID 및 url/href 참조에 인스턴스별 접두사를 붙이세요.
- 주황 링과 해 색·크기·위치는 기존 그대로입니다. 하늘만 토큰의 seasons.{season}.sky를 사용합니다. 원 중심90,90 그림클립r73.
- 40px에서 lg-only와 collected-only 그룹을 숨기고 필터를 제거합니다. 기본 능선 그라데이션은 유지합니다. 봄 잔설과 여름 물은 이 크기에서 제외됩니다.
- 미모음은 기존 단색 실루엣 렌더를 사용합니다. 새 자체색 SVG에 ridge CSS 변수만 바꾸는 방법으로는 단색이 되지 않습니다. 모든 그림 fill/stroke와 gradient 참조를 #D4DACE로 치환하거나 승인된 기본 실루엣을 단색 렌더하세요. lg-only/collected-only는 숨기고 후경 opacity1, 필터 제거.
- 봄 1500m 이상 자체 잔설, 여름·가을 눈 없음, 겨울 자체 눈: 호스트 자동 눈은 모든 계절에서 끕니다. 기존 자동 장식 전경도 새 그림에 중복하지 않습니다.

standalone의 완성 SVG는 색과 심볼을 모두 해석한 독립 파일입니다. 코드 적용 없이 디자인을 확인할 때 사용하세요. PNG는600×600 투명 배경 스탬프입니다. 원본 앱 저장소는 수정하지 않았습니다.
