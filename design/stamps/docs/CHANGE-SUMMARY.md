# 마지막36곳 — 변경 요약

강원18곳과 전라18곳을 추가해 전체126곳의 디자인 파일을 갖췄습니다. 기존90개 팔레트 매핑과15개 모티프 파일은 그대로 보존합니다. 기본36개, 계절144개, 돌탑cairn1종을 새로 만들었습니다(총16종/상한18종).

## 봄과 겨울

가리왕산1562m·계방산1579m·오대산1565m·덕유산1614m: 봄에는 연두·군락 위 정상부만 잔설, 겨울에는 능선 중간까지 넓은 설면을 둡니다. 40px에서는 계절 장식을 생략하는 기존 규칙을 유지하므로 잔설·확장 설면보다 산의 봄색과 겨울색으로 구분합니다.

600m 미만 팔봉산328m·깃대봉368m·강천산586m·변산509m: 이번 명시 지시에 따라 겨울 눈 캡·하단 설면·눈 입자를 모두 제외합니다. 기존 다른 묶음의 겨울 파일을 일괄 바꾸지는 않았습니다. 밝은 암벽 면은 바위 표현으로 남습니다.

팔레트는 붉은 단풍형33곳, 황금 초원형3곳(명성산·장안산·덕유산)입니다. 링·해·질감·좌표계·미모음 변환은 기존 규칙을 따릅니다.

## 산별 기준

마이산은 이전2묶음 표에 없었고 이번 표에 있으므로 신규로 제작했습니다. 암마이봉 중심의 두 귀 형태입니다. 덕유산은 표의 중봉 구도를 기준으로 하며1614m는 제공된 산 표기값입니다. 향적봉이라는 지점명으로 바꾸지 않았습니다. 대둔산은 기존2묶음에 있으므로 다시 만들지 않았습니다. 치악산은 비로봉 돌탑, 팔영산은5봉을 중심으로 연결된 암릉을 표현했습니다.

두타산 베틀바위는 정상과 동일 지점이라고 주장하지 않는 측면 암봉 모티프로 사용했습니다. 모든 그림은 상징적 구도이며 DEM나 정확한 정상 조망을 대조 완료한 파일은 아닙니다.
