# 계절 강조 2차 — 변경 요약

**봄·여름·가을의 산 자체를 넓은 색면으로 바꿨습니다.** 하늘과 작은 장식에만 기대던 표현을 바꾸고, 40px에서도 남는 전경 색으로 계절을 구분했습니다.

| 계절 | 바뀐 표현 |
|---|---|
| 봄 | 회갈색 정상에서 연두색 아래 능선으로 이어지는 부드러운 색 변화. 분홍 군락의 면을 넓히고, 소백산·무등산·지리산은 더 넓게 적용. 1500m 이상 잔설 추가. |
| 여름 | 전경은 가장 짙은 녹색, 후경은 밝게 해 명암차 강화. 청록 계곡·백록담 수면·주왕산 협곡 물·지리산 운무를 넓은 면으로 표현. 하늘 #C7E4EF. 눈 없음. |
| 가을 | 붉은 정상→주황→황토→아랫부분 녹색. 태백산·소백산은 황금·은빛 초원형. 뒤 능선은 덜 물든 주황·황토. 하늘 #E5EBE7. |
| 겨울 | 합격한 원본 파일 그대로. 색·설면·상고대·형태를 변경하지 않음. 기존 낮은 산의 겨울 녹색도 유지. |

**지킨 것:** 기본판10개, 모티프9파일, 산 실루엣·모티프 배치, 질감 필터, 주황 링 r85/r77, 주황 해 r20와 배치. 고도4색은 봄·여름·가을만 해제했고 겨울은 원본을 보존했습니다. 해 색 변경은 이번에 제안하지 않습니다.

**작은 크기:** 40px에서는 군락·물·잔설 등 계절 장식과 필터가 빠지지만 능선 그라데이션은 남습니다. 미모음은 원본 단색 #D4DACE와 같은 윤곽입니다. 겨울 모음은 주황 링·해와 유색 산이 남아 미모음과 구분됩니다.

**팔레트 재사용:** 붉은 단풍형8곳과 황금 초원형2곳을 season-tokens.json에 기록했습니다. 96곳 확장은 지형·식생 인상으로 배정하고 고도로 자동 분류하지 않습니다. 높은 산 신호는 봄 잔설로 일부 남겼으나 40px에서는 계절 구분을 우선합니다.

**납품:** 계절 그림40개, 독립형 SVG/600px PNG40쌍, 크기·상태별240쌍, 요청한 판정 시트4장, 계절 토큰·확장 규칙·적용 안내. 각 계절 그림과 참조 모티프 합산8KB 미만, 필터1개·프리미티브3개 이하. 수치 검사 결과는 validation.json.

실제 앱 반영·사용자 식별 테스트는 별도입니다. 산별 물길·꽃 군락은 상징적 표현이며 실측 생태·조망을 재현하지 않습니다.
