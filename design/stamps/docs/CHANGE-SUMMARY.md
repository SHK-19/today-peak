# 2묶음 변경 요약 — 경상·충청38

기존과 같은 링·해·팔레트·질감·상태 규칙으로38곳을 추가했습니다. 의뢰서 표의 ID·산명·높이·지역·인증 지점을 그대로 사용했습니다. 기본38개 + 계절152개이며 기존52곳의 매핑을 보존한90개 계절 토큰을 제공합니다.

## 형태와 계절

상왕봉의 겹친 바위, 삼불봉의 세 봉우리, 영봉의 수직 암벽, 대둔산의 구름다리로 주요 산의 인상을 구분했습니다. 불필요한 모티프는 넣지 않았습니다. 기존13모티프 파일은 바이트 단위 그대로이며, 구름다리 bridge와 단일 수직 암벽 sheer-face만 새로 만들어 총15종입니다.

붉은 단풍형33곳, 황금 초원형5곳(신불산·재약산·천성산·화왕산·황매산)으로 배정했습니다. 봄 연두·군락, 여름 짙은 산·물빛, 가을 단풍/황금 그라데이션, 겨울 고도색·눈은 유지합니다. 1500m 이상은 없어 봄 잔설은 없습니다.

## 용량

그림 자체를 바꾸는 대신 불필요한 데이터 속성과 반복되는 긴 내부 ID를 줄였습니다. 계절 파일당2500바이트 이하, 사계절 합계8000바이트 이하를 각각 검사합니다. filter1개·프리미티브3개를 유지합니다. 계절 파일 최대1715바이트, 사계절 합계 최대6440바이트입니다.

## 인증 지점 우선 해석

마이산은 본문의 랜드마크 예시에 있지만38행 표에는 없어 이번에 포함하지 않았습니다. 팔공산의 인증 지점은 동봉이므로 관봉의 갓바위를 동봉으로 그리지 않았습니다. 속리산은 문장대 대신 표에 명시된 천왕봉을 기준으로 잡았습니다. 운문산은 함화산1107m라는 지점명을 보존하면서 앱 표기고도1195m는 바꾸지 않았습니다. 유명한 랜드마크가 인증 지점과 같은 곳이라고 주장하지 않습니다.

## 확인 범위

파일 검사와 기존 빌드 스크립트의 격리된 복사본 검사를 마쳤습니다. 수정하지 않은 기존 스크립트가90곳을 읽었고, 실제 prepareArt 함수1440개 상태 조합도 통과했습니다. 운영 저장소는 수정하지 않습니다. 실제 조망·DEM·등산자의 이름 없는 식별률·실기기 성능은 이번에 검증 완료로 처리하지 않습니다. 산체는 인증 지점의 인상을 상징적으로 단순화한 그림입니다.
