# 오늘 정상 · 디자인 명세

## 방향

**오늘 오른 산이, 오래 남는 기록으로.**

젊은 주말 등산객이 작은 등산 수첩을 모으듯 쓰는 화면입니다. 따뜻한 종이색과 여유 있는 정렬로 차분하게 구성하고, 실제 획득한 스탬프에만 계절색과 주황 테두리를 부여합니다. 성공 화면은 초록 바탕 위 절취선이 있는 종이 카드로 기억에 남게 합니다. 이 문장의 슬로건은 디자인 보드용 설명이며 앱 화면에 추가하지 않았습니다.

이미 확정한 앱 로고와의 연결을 위해 브랜드 두 값은 **#1F6B4A / #E8622C**를 사용합니다. 로고 파일은 수정하지 않았습니다.

## 납품물과 확인 방법

- `screens/`: 화면별 375px PNG 및 편집 가능한 SVG 24종. SVG는 텍스트·도형으로 구성되어 디자인 도구에서 수정할 수 있습니다.
- `design-preview.png`: 성공·컬렉션·홈을 함께 비교하는 이미지. 컬렉션은 긴 화면의 상단 일부입니다.
- `index.html`: 화면을 분류해서 보는 디자인 보드. 압축을 풀고 브라우저로 열면 됩니다.
- `app.html`: 시연용 화면. 실제 네트워크 요청 없이 화면을 이동합니다.
- `src/styles/tokens.css`: 최종 색·서체 크기·간격 토큰.
- `src/styles/screens.css`: 화면 구현 참고 CSS.
- `src/stamps.js`: 산별 seed, 고도, 계절, 모음 여부로 생성하는 SVG 스탬프 컴포넌트.
- `src/screens.js`: 화면·상태 구성 및 상호작용 참고 코드.
- `validation.json`: 파일 규격·상태 렌더링·도장 생성·대비 계산 결과.

PNG는 **SVG 디자인 프레임을 렌더한 이미지**이며, 브라우저 스크린샷이 아닙니다. 정적 프레임을 시각 명세로, HTML/CSS는 반응형 화면 구현 참고로 사용합니다. 브라우저의 줄 높이·하단 고정·스크롤 동작에 따라 세로 배치는 정적 프레임과 달라질 수 있습니다. 현재 환경에서 브라우저의 로컬 파일 접근이 차단되어 브라우저 시각 검증과 실기기 검증은 진행하지 못했습니다.

실제 앱 소스와 산 목록 원본은 제공되지 않았습니다. 예시 산 27곳과 예시 날짜·집계·거리로 디자인했습니다. 96곳 전체 목록이나 실제 GPS 기능을 새로 구축한 결과물이 아닙니다. 수도권은 14칸 모두 제시하고, 나머지 권역은 대표 칸으로 스타일을 제시했습니다. 데이터 항목을 추가하면 같은 반복 컴포넌트가 늘어나며 권역은 접지 않습니다. **권역별 전체 수·고도·거리·날짜는 디자인 예시로, 운영 데이터의 검증 결과가 아닙니다.**

## 스탬프

### 모음과 미모음

| 상태 | 형태 | 정보 |
|---|---|---|
| 모음 | 선명한 주황 이중 링, 계절색 하늘, 고도별 산색. 큰 사이즈에만 미세 잉크 입자 | 산 이름 + 인증 날짜 |
| 미모음 | 연한 녹회색 면과 양각·음각을 연상시키는 두 겹 선. 해·계절색·잉크 입자 제거 | 산 이름 + 고도 |

미모음의 **텍스트까지 희미하게 만들지는 않습니다.** 도장 그림만 흐리게 두고 산 이름과 고도는 읽을 수 있는 대비를 유지합니다. 40px에서는 텍스처를 없애고 외곽 선을 상대적으로 두껍게 사용합니다. 원 안에 산 이름이나 고도는 넣지 않습니다.

### 크기

- **40px**: 홈 목록. 40×40 이미지 + 88px 이상 목록 행.
- **76px**: 컬렉션. 3열, 327px 가용폭에서 열 간격 8px, 각 칸 약 103.7px. 산 이름까지 클릭 영역에 포함.
- **160px**: 상세·성공·인트로. 자세한 도장 감상용.

SVG viewBox는 180×180입니다. 바깥 원은 중심 (90,90), 반지름 85. 기본 외곽 선 4, 40px용 외곽 선 7. 안쪽 링 반지름 77, 폭 1.5. 그림은 반지름 73으로 클리핑합니다. 숫자는 viewBox 단위입니다.

### 자동 생성 규칙

`stampSVG({ seed, height, collected, size, season, label })`

- `seed`: 운영 데이터의 고정 ID에서 만든 안정적인 수. 이름 정렬이나 목록 순서가 바뀌어도 같은 seed를 유지합니다.
- 능선: 기본 능선 4종에 seed 기반 좌표 변화를 적용합니다. 실제 산의 지형을 재현하는 지도·일러스트가 아니라 상징적 능선입니다.
- `<600m`: `#6E955C`
- `600~999m`: `#377650`
- `1000~1499m`: `#245744`
- `1500m 이상`: `#30485A`
- 1000m 이상 **모음** 스탬프에 흰 눈 캡. 미모음은 색을 뺀 실루엣으로 통일.
- 봄 `#EFDED6` / 여름 `#DEE8DF` / 가을 `#F2D4B5` / 겨울 `#DAE7E9`.
- 인증 시점의 계절을 기록에 저장합니다. 현재 계절이 바뀌었다고 기존 스탬프 색이 바뀌면 안 됩니다.
- `label`에는 앱 내부에서 검증된 산 이름만 전달합니다. 외부 문자열을 직접 전달할 경우 XML 이스케이프가 필요합니다.

## 화면별 명세

### 인증 성공 · success

초록 배경 전체에 흰 성공 제목 24px, 설명 15px. 제목 아래 24~32px 간격으로 종이 카드가 놓입니다. 카드 폭 327px, 반경 24px. 160px 도장, 산 이름 32px, 고도·봉우리 15px, 날짜 15px을 중앙 정렬합니다. 절취선 아래에는 모은 스탬프 요약이 옵니다. 하단 CTA는 흰색 바탕·초록 글자입니다.

애니메이션은 **680ms**입니다. 0%에서 1.3배/−13°/투명, 42%에서 0.95배/−5°, 63%에서 1.035배, 100%에서 1배/−5°. 과한 파티클과 반복 동작은 없습니다. `prefers-reduced-motion`에서는 즉시 완성 상태를 표시합니다.

### 저장 실패 · save-error

같은 종이 카드와 도장을 유지합니다. 카드 밑에 확정된 실패 문구를 추가하고 버튼은 ‘다시 저장’으로 변경합니다. 실제 연동 시 재저장은 위치 인증을 반복하지 않고 이미 확인한 결과의 저장을 재시도해야 합니다. 스탬프 획득과 저장 완료를 별개의 상태로 관리하세요.

### 컬렉션 · collection / collection-empty

상단 종이색 영역: 제목 32px, 부제 15px, 진행 막대 높이 6px. 권역마다 헤더 20px/600, 집계 15px. 도장 76px, 이름 15px, 날짜 13px. 3열의 일정한 중심축을 유지합니다. 긴 이름은 2줄이 될 수 있으며 말줄임으로 자르지 않습니다. 권역 접기 기능을 두지 않습니다.

0개여도 기존 그리드를 유지합니다. 안내는 진행 막대 아래 추가합니다. 기존 모음 날짜를 숨기고 고도를 표시합니다.

### 산 상세 · detail / detail-collected

종이색 히어로 영역 높이 240px, 스탬프 160px 중앙. 제목 32px, 인증 지점 포함 부제 15px. 주의해서 읽어야 하는 핵심은 산 이름·인증 지점·인증 행동입니다. 집계 3줄은 15px 보조 영역에 분리하며, 각 값이 0이면 그 줄을 제거합니다. ‘산행 시작’은 보조, ‘정상 인증하기’는 주 CTA로 구분합니다. 산행 시작을 지원하지 않는 산에서는 보조 버튼 자체를 숨깁니다.

모음 상태에는 색 있는 스탬프와 ‘이 산의 스탬프를 모았어요’ 배지가 붙습니다. HTML 예시는 기본/모음 상태를 별도로 선택해 볼 수 있습니다. 운영 코드에서는 실제 획득 여부로 결정해야 합니다.

### 홈 · home / home-denied

제목 32px, 부제 15px. 권역 칩 높이 44px, 가로 스크롤. 목록 행 최소 88px, 세로 패딩 16px, 스탬프40과 텍스트 간격16px. 목록 이름17px/600, 고도·거리15px. 모음 배지는13px. 이동 꺾쇠는 SVG입니다.

위치 거부 상태는 안내 상자와 ‘위치 허용하기’를 추가하고 목록의 거리만 제거합니다. 권역 필터와 목록 진입은 유지합니다. 시연 코드에서 권한 버튼은 상태만 변경하며 실제 위치 권한 요청을 하지 않습니다.

### 로그인 · login / login-loading / login-error

앱명40px, 부제17px, 히어로160px. 로그인 실패/로딩 문구가 들어갈 최소80px 영역을 미리 확보합니다. CTA는 하단에 하나만 배치합니다. 로딩 동안 중복 탭을 막습니다.

### 인증 실패 · fail 및 기타 결과

카드는 종이색, 반경24px, 내부24~32px. 제목28px, 본문17px. 제보 링크는 초록15px 밑줄로 표현해 메인 인증 버튼과 구분합니다. 누를 수 있는 높이는56px을 유지합니다. 다른 실패 제목에도 같은 카드 틀을 사용합니다. 의뢰서에 없는 실패 본문을 임의로 길게 추가하지 않았습니다.

### 정상 제안 · report / report-done

라벨24px/700, 입력창 최소56px, 20자 제한. 개인정보 안내15px, 행간 약1.7. 입력하지 않고 보내면 필드 옆 오류를 표시합니다. 키보드가 뜬 실기기에서 입력창과 CTA가 가리지 않도록 화면 스크롤 및 viewport 조정을 확인해야 합니다. 시연에서는 입력값·위치를 전송하지 않습니다.

### 위치 권한 · permission

초록 계열 아이콘80px 영역, 제목28px, 본문17px. 하단56px CTA. 실제 앱에서는 권한 결과에 따라 다시 상세 또는 동일 안내 화면으로 돌아오게 하며, 플랫폼 뒤로가기 경로를 유지해야 합니다.

### 탭바

홈·내 스탬프만 사용합니다. 아이콘24px, 라벨13px, 각 탭은 넓이의 절반, 탭 본체 높이52px 이상. 상단 패딩8px, 하단 safe area34px. 활성 색은 초록이며 굵기도 달라집니다. 로그인·상세·성공·실패·입력에는 넣지 않습니다.

## 확정 문구와 새 보조 문구

의뢰서 따옴표 안 문구는 단어를 바꾸지 않았습니다. 디자인 보드의 설명은 제품 문구가 아닙니다. 아래는 의뢰서에서 문구가 지정되지 않은 상태의 **신규 제안**으로, 운영 반영 시 검토 대상입니다.

- 버튼: 내 스탬프 / 홈 / 위치 허용하기 / 다시 시도
- 인증 중: 위치를 확인하고 있어요
- 산행 시작 후: 산행을 시작했어요
- 목록 로딩: 산 목록을 불러오고 있어요
- 목록 실패: 산 목록을 불러오지 못했어요
- 빈 입력: 봉우리 이름을 입력해 주세요.

## 연동 경계

디자인 미리보기는 로그인·위치 확인·저장·산행·제보를 시뮬레이션합니다. `src/screens.js`의 `act()`를 운영 서비스로 그대로 사용하면 안 됩니다. 실제 기존 앱의 인증·저장·오류 결과에 화면만 연결하세요. 개인정보나 위치를 새로 수집하는 코드가 없습니다.

플랫폼 뒤로가기·홈 이벤트와 실제 권한 처리, 키보드 대응, 인증 성공 후 저장 재시도, 96곳 데이터 바인딩은 기존 앱과 연동할 때 확인해야 합니다. `index.html`의 디자인 보드 도구와 설명은 운영 화면에 포함하지 않습니다.

- [Safe Area](https://developers-apps-in-toss.toss.im/documentation/common/screen/safe-area): `SafeAreaInsets.get()` 및 `subscribe()`로 실제 inset을 읽는 방식을 확인했습니다. 34px은 본 의뢰서의 디자인 기준이며 모든 기기의 고정된 공식 값으로 단정하지 않습니다.
