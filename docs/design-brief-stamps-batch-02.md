# 스탬프 확장 의뢰서 — 2차 묶음 (경상·충청 38곳)

1차 묶음(수도권 42곳) 잘 받았습니다. 앱에 통합해서 실제로 돌아가는 것까지 확인했고, 그 결과를 아래 "1차에서
확인된 것"에 적었습니다. **규칙은 하나도 바꾸지 않습니다.** 2차는 같은 시스템으로 38곳만 더 그려 주시면 됩니다.

기준 문서는 그대로입니다.
- `docs/design-brief-stamps.md` (시제품 의뢰서 — 스탬프 시스템 원본)
- `docs/design-brief-stamps-seasons.md` (계절 강조 추가 의뢰서)
- `docs/design-brief-stamps-batches.md` (3묶음 확장 의뢰서 — 이 문서의 상위)

---

## 1차에서 확인된 것 (기술 검수 완료)

- 42곳 × 4계절 168개 파일이 파이프라인에 그대로 물렸습니다. `scripts/build-stamp-art.mjs`를 고칠 일이 없었습니다.
- `season-tokens.json`이 기존 10곳을 포함한 상위집합이라 병합 사고가 없었습니다. 2차도 **52곳 + 신규 38곳 = 90곳**을
  담은 상위집합으로 주세요. 기존 매핑을 지우지 말아 주세요.
- 기존 모티프 9종이 바이트 단위로 같아서 교체가 안전했습니다. 2차에서도 기존 파일은 건드리지 말아 주세요.
- 용량: 산+모티프 최대 2,673바이트였습니다. 앱 번들이 이 값에 직접 비례합니다(아래 "용량" 참고).
- 홈 목록 40px과 컬렉션 76px에서 42곳이 서로 다른 실루엣으로 보입니다. 남산(타워)·관악산(연주대 정자)처럼
  모티프가 있는 산은 작은 크기에서도 바로 읽힙니다.

**아직 안 끝난 것**: 실루엣이 실제 산과 닮았는지, 이름을 가리고도 구분되는지는 사람 눈으로 보는 검수라 진행 중입니다
(납품의 `demValidated: false`, `nameBlindRecognitionTested: false`와 같은 항목입니다). 여기서 고칠 게 나오면 2차 작업
중이라도 바로 알려드립니다. **그 가능성을 감수하고 2차를 시작해 주세요** — 지금까지 확인된 범위에서는 시스템을
바꿀 이유가 없습니다.

## 2차 묶음: 경상 28곳 + 충청 10곳 = 38곳

고도 분포는 1,000~1,499m가 16곳, 600m 미만이 5곳입니다. **1,500m 이상은 한 곳도 없습니다** — 봄 잔설 규칙
(1,500m 이상만 잔설)을 쓸 산이 이 묶음에는 없다는 뜻입니다. 겨울은 고도색 + 눈, 봄은 잔설 없이 갑니다.

시제품·1차에 이미 있는 지리산·주왕산·소백산·무등산과 나란히 놓입니다. 톤을 맞춰 주세요.

## 모티프

1차까지 13종입니다. **기존 13종을 먼저 쓰고**, 이 묶음의 랜드마크가 어느 것으로도 안 되면 새로 만들어 주세요.
새 모티프는 **최대 5종(총 18종)**까지로 부탁드립니다.

```
altar  cliff  cloud-sea  columns  crater  dead-tree  fortress
meadow  pavilion  rock-dome  rock-spire  rock-wall  tower
```

1차에서 20곳이 모티프 없이 산체만으로 갔습니다. 그 판단이 좋았습니다. 억지로 붙이지 말아 주세요.

---

## 용량 (1차보다 중요해졌습니다)

산 그림은 전부 앱 번들에 들어갑니다. 52곳에서 411KB, 번들 gzip 132KB입니다. 90곳이면 700KB 안팎이 됩니다.
**계절 파일 하나당 2.5KB를 넘지 말아 주세요** (1차 최대 2,673바이트). 이 선만 지키면 3차까지 쪼개기 없이 갑니다.

- 산당 8KB(4계절 합계), 필터 1개, 프리미티브 3개
- 래스터·글자 없음, 외부 참조는 `motifs/`의 `<use href>`만

- `stamps/{id}.svg` 38개

- `season-tokens.json` — 90곳 상위집합

- `docs/CHANGE-SUMMARY.md`

`preview/`와 `standalone/`은 저장소에 넣지 않으니 필요하시면 만드시되 없어도 됩니다.

## 합격 기준 (변경 없음)

- 76px에서 이름 없이 묶음의 절반 이상 식별(등산 경험자)
- 하늘을 회색으로 통일해도 사계절이 갈림
- 40px 미모음에서 같은 지역 산끼리 구분됨
- 시제품 10곳·1차 42곳과 나란히 놓았을 때 한 시스템
- 계절 파일 2.5KB 이하
