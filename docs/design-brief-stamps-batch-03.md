# 스탬프 확장 의뢰서 — 3차 묶음 (강원·전라 36곳, 마지막)

2차 묶음(경상·충청 38곳) 잘 받았습니다. 1차와 마찬가지로 파이프라인 수정 없이 그대로 들어갔고,
계절 파일 최대 1,715바이트로 2.5KB 상한 안에서 여유 있게 끝났습니다. 이번이 **마지막 묶음**입니다 —
이걸 받으면 126곳 전부가 고유 그림을 갖게 됩니다.

기준 문서는 그대로입니다.
- `docs/design-brief-stamps.md` (시제품 — 스탬프 시스템 원본)
- `docs/design-brief-stamps-seasons.md` (계절 강조)
- `docs/design-brief-stamps-batches.md` (3묶음 확장 — 이 문서의 상위)
- `docs/design-brief-stamps-batch-02.md` (2차 — 용량·모티프 규칙은 여기 그대로)

---

## 2차에서 확인된 것

- 38곳 × 4계절 152개 파일 통과. `season-tokens.json` 90곳 상위집합, 기존 모티프 13종 바이트 동일.
- 새 모티프 2종(bridge, sheer-face) 추가로 총 15종. 2차에서 허용한 5종 중 2종만 써서 절제가 좋았습니다.
- 번들: 90곳에서 stamp-art.json 689KB, 앱 번들 gzip 147KB. 126곳이면 gzip 160KB 안팎으로 예상돼
  **쪼개기 없이 갑니다.** 계절 파일 2.5KB 상한은 3차에도 그대로입니다.

육안 검수(실루엣 사실성·이름 가린 식별)는 1·2차를 묶어서 진행 중이고, 고칠 게 나오면 3차 작업 중에 알려드립니다.

## 3차 묶음: 강원 18곳 + 전라 18곳 = 36곳

**이 묶음의 핵심은 겨울과 봄 잔설입니다.** 1,500m 이상이 4곳(덕유산 1,614·계방산 1,579·오대산 1,565·가리왕산 1,562)이고
1,000~1,499m가 12곳입니다. 봄 잔설 규칙(1,500m 이상만)을 실제로 쓰는 산이 전부 여기 있습니다.
시제품의 설악산·태백산·한라산·지리산 겨울 톤과 나란히 놓입니다.

## 모티프

현재 15종입니다. **기존 15종을 먼저 쓰고**, 안 되면 새로 만들되 **최대 3종(총 18종)**까지로 부탁드립니다.

```
altar  bridge  cliff  cloud-sea  columns  crater  dead-tree  fortress
meadow  pavilion  rock-dome  rock-spire  rock-wall  sheer-face  tower
```

돌탑(치악산 비로봉)이나 상고대(덕유산)는 새 모티프 후보입니다. 모티프 없이 산체만으로 충분하면 그렇게 가 주세요.

## 겨울·봄 잔설 (이 묶음에서만 특별히)

- 1,500m 이상 4곳은 **봄에 잔설**이 남습니다. 봄 팔레트 위에 능선 상단만 흰색이 남는 정도로, 겨울과 헷갈리지 않게.
- 겨울은 고도색 하나 + 눈. 1,500m 이상은 눈이 능선 절반 아래까지 내려와도 됩니다(덕유산 향적봉의 실제 인상).
- 600m 미만 4곳(강원 팔봉산 328m 등)은 겨울에도 눈을 얹지 않습니다 — 1차 동네 명산과 같은 규칙.

## 용량·납품물 (2차와 동일)

- 계절 파일 2.5KB 이하, 산당 8KB(4계절 합), 필터 1개, 프리미티브 3개, 래스터·글자 없음
- `stamps/{id}.svg` 36개, `seasons/{season}/{id}.svg` 144개, `motifs/` 기존 15종 그대로 + 신규분
- `assignments.json/.csv` 이번 36곳만, `season-tokens.json` **126곳 상위집합**
- `sheets/`, `validation.json`, `docs/CHANGE-SUMMARY.md`. `preview/`·`standalone/`은 없어도 됩니다

## 합격 기준 (변경 없음)

- 76px에서 이름 없이 묶음의 절반 이상 식별
- 회색 하늘로 통일해도 사계절이 갈림 — **이 묶음은 특히 겨울/봄 잔설이 구분돼야 합니다**
- 40px 미모음에서 같은 지역 산끼리 구분됨
- 시제품 10곳·1차 42곳·2차 38곳과 나란히 놓았을 때 한 시스템

## 마지막으로

3차가 들어오면 126곳 전체 시트를 한 장으로 만들어 최종 검수를 합니다. 거기서 나온 수정은 묶음이 아니라
산 단위로 요청드릴 예정입니다.
